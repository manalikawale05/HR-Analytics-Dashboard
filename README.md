# HR Analytics Dashboard – Power BI

## Project Overview
This project analyzes employee attrition using Power BI. The dashboard helps understand employee turnover across different demographics and job-related factors.

## Tools Used
- Power BI
- Power Query
- DAX

## Key Performance Indicators (KPIs)
- Total Employees: 1,470
- Attrition Count: 237
- Attrition Rate: 16.12%
- Active Employees: 1,233
- Average Employee Age: 36.92
- Average Monthly Salary: 6.50K
- Average Years at Company: 7

## Dashboard Analysis
- Attrition by Gender
- Attrition by Age
- Attrition by Department
- Attrition by Job Role
- Attrition by Salary Slab
- Attrition by Education

## Key Skills Demonstrated
- Data Cleaning and Transformation
- Data Visualization
- DAX Measures
- Interactive Slicers
- HR Data Analysis

## Conclusion
The dashboard provides insights into employee attrition patterns and helps HR teams identify areas that may need attention.
